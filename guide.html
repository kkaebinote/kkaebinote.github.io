뉴비 30만 투력 가이드

무과금 기준 · 2026.11.02 커뮤니티 공략 기준 · 수요일 점검마다 밸런스가 바뀔 수 있음

투력 30만까지는 희귀 장비 풀강 → 황무지 자동사냥 → 영웅 장비 제작 → 영웅 돌파·각성 네 단계다. 메인·서브퀘만 성실히 밀어도 13만 안팎까지는 자연스럽게 오른다.

  • 투력이 막히면 레벨보다 강화부터. 희귀(파란) 장비는 끝까지 강화해야 진행된다.
  • 영기 수련은 쉬는 시간이 없게. 게임 끄기 전 수련이 돌고 있는지 확인.
  • 엽전·요혼석은 금방 바닥난다. 상점 구매와 고급 강화는 우선순위대로만.

투력은 어디서 오나

성장 요소우선도메모
장비 강화·돌파·각성최상희귀 장비 전 부위 50강 시 약 8만대. 1회 강화 엽전 약 1.5만
영기 수련최상공격·방어·체력, 도술 슬롯 개방. 공백 시간 최소화
기운 발현상생명의 기운: 체력·방어·회피·자연회복. 보스에 자주 눕으면 여기부터
도술 강화중요령서는 한정 재화라 신중하게
몬스터 화첩중사냥하며 자연스럽게 채움
영웅 장비13만 이후 핵심황무지 도안 + 전래동화 비경·레이드 재료

투력이 보스 권장치보다 낮아도 공략은 가능하다. 권장 8.7만인 산군대호를 4.7만~6.3만에서 잡은 사례가 있다. 자동전투를 끄고 패턴을 직접 피할 것.

단계별 로드맵

1단계 · 시작 ~ 레벨 50 · ~5만
  1. 쿠폰부터 전부 입력. 홈의 미사용 쿠폰 목록 참고.
  2. 레벨 30까지 메인퀘만 직진. 새 기능은 퀘스트 안내대로만.
  3. 레벨 30 희귀 장비 선택상자: 무기는 부채가 정배(방향 없으면 활도 무난), 방어구는 투구 → 허리띠.
  4. 희귀 장비 강화 비법서는 아끼지 말 것. 무기 강화·돌파·각성 → 팔찌 → 투구 → 반지.
  5. 기운 선택상자: 홍염 빼고 고르게, 생명의 기운 비중 챙기기.
  6. 타바로성 도착 즉시 문파 가입 → 파멸 도술 습득·교체.
  7. 도술 강화 요령서 선택상자는 보관.
2단계 · 레벨 50 ~ 13만
  1. 레벨 50 도술 선택상자로 '생명의 흐름' 습득.
  2. 메인 + 서사(서브)퀘 병행. 비명동굴 즈음 막히면 서브퀘·일일 임무 정리.
  3. 희귀 장비 전 부위 50강 → 돌파 → 각성. 중복 장비는 각성 재료라 분해 금지.
  4. 흰색 귀걸이·목걸이도 끝까지 강화.
  5. 딜이 부족하면 무기·반지 강화, 영기 수련도 공격력 위주.
  6. 놓친 보물상자 수집 (홈 → 바로가기 → 보물상자 지도).

목표 스펙: 투력 12~13만

3단계 · 13만 ~ 20만
  1. 필드보스(매일 20시)·문파 콘텐츠 필수.
  2. 금전으로 전투 멤버십부터 구매. 도술 슬롯 +1, 원격 엽전 상점.
  3. 14~15만 세팅: 빠진 파란 방어구는 거래소 구매. 기준 공격력 1.4k, 회피·자연회복 각 1,300 전후.
  4. 황무지 마을 13.5k 몹 자동사냥: 강타 + 파멸, 유틸 생명의 흐름·방패밀기·공간결계. 물약 없이 분당 엽전 700~800이 기준.
  5. 영웅 도안 + 재료로 제작: 무기 > 허리띠 > 투구 > 신발 / 팔찌 > 반지 > 귀걸이. 무기는 활만 아니면 나오는 대로.
  6. 원님고개(관아)는 주 5시간, 수요일 05시 리셋 → 화요일에 몰아서.
  7. 영웅 장비 분산 강화: 무기 1돌파 → 허리띠·팔찌 49강 → 반지 49강 → 나머지 30강.
  8. 레이드 티켓은 15만 전까지 보관(최대 10장). 17만·공격력 1.7k부터 S등급(9분 이상 남김) 노리기.
  9. 낙화의 전장은 1급 도사만 달성(시즌 종료 금전 약 8천).
4단계 · 20만 ~ 30만

원칙은 "영웅 장비를 넓게 채우고, 그다음 깊게 올린다".

  1. 영웅 무기 풀강 후 2~3돌파. 무기 비법서는 방어구의 3배 이상이라 3돌파에서 멈춘다.
  2. 영웅 방어구 6부위 제작. 허리띠·투구 먼저.
  3. 레이드 3단계 S등급 반복. 영웅 장신구 도안은 여기서만 확률 드랍, 클리어마다 영웅 재료 선택상자. 장신구는 반지 > 팔찌 > 귀걸이.
  4. 영웅 무기 1각성. 중복 무기 남겨두기.
  5. 영웅 방어구 6부위 1돌파 → 1각성 → 2돌파.
  6. 여유가 생기면 전설 무기 파밍. 전설 도안 거래소 구매 금지.

재료 수급 포인트

  • 강화 비법서: 엽전 상점(1.5만 엽전, 주 50개) + 멤버십 원격 상점 50개 + 단각 교환(20→1, 일 20개).
  • 비경 일일 1시간: 강화 재료 부족 → 영험한 청산 지하동굴 / 요혼석 → 망자의 마을 / 엽전 → 옛 귀족 지구. 노물약으로 버티는 최고 단계.
  • 전래동화 비경 주 5시간: 팥쥐의 들녘(별의 조각) → 도안 생기면 원님고개.
  • 사냥터 이동 기준: 노물약 + 분당 처치 수가 황무지 이상이면 위로, 물약을 먹으면 한 단계 아래로.

20만 이후 구간은 공략 자료가 아직 적다. 순서는 커뮤니티 공통 의견 기준이며, 사냥터·도술 빌드는 최신 갤러리 글로 한 번 더 확인할 것.

자주 묻는 질문

보스가 안 잡혀요.
자동전투 끄기, 영기 수련으로 도술 슬롯 확장, 생명의 기운 강화. 보스전은 절명 도술 3개 + 요혼격 조합도 추천된다.
메인퀘가 비명동굴에서 막혔어요.
정상. 서브퀘·일일 임무 정리 후 희귀 장비 강화를 끝내면 다시 진행된다.
엽전이 계속 모자라요.
노물약 사냥 수익(분당 700~800)을 기준으로, 엽전 비경(옛 귀족 지구)도 활용. 상점 순서를 지킨다.
도술 요령서는 언제 쓰나요?
성장 구간에 20~30강까지 올리면 사냥 속도가 확실히 빨라진다. 엽전 상점 구매는 신중하게.
20만 이후 뭘 먼저 올리나요?
영웅 무기 2~3돌파 → 방어구 6부위 제작 → 레이드 3단 S로 장신구. 한 부위 몰빵보다 부위 수를 먼저 채운다.
